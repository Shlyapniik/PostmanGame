# PostmanGame

A narrative-driven 2D adventure game developed with Unity and C#.

## About

PostmanGame is a story-focused game where the player takes the role of a postman delivering letters, meeting townspeople, and uncovering their stories.

Player choices influence conversations, relationships, and quest progression.

## Features

- Top-down 2D movement and interaction
- Branching dialogue system
- Story flags and persistent decisions during gameplay
- Daily mail delivery system
- Quest system with sequential objectives
- Quest journal
- Story item inventory
- Data-driven NPC dialogues using ScriptableObjects

## Technologies

- Unity 2D
- C#
- TextMeshPro
- ScriptableObjects

## Development Status

**In development — early playable prototype.**

The core gameplay systems are being developed. Story content, saving/loading, visual assets, and UI improvements are planned.
